## System Settings
- [ ] Hostname: change from default "My-Mac"
- [ ] Trackpad → Scroll → turn off Natural scrolling (an abomination)
- [ ] Keyboard → Key repeat rate, Delay until repeat
- [ ] Screenshot.app (open it) → change save location ("Desktop" sucks)
- [ ] Desktop & Dock → Automatically hide and show the Dock (on)
- [ ] Desktop & Dock → Automatically rearrange Spaces based on most recent use (off)
- [ ] Desktop & Dock → Click wallpaper to reveal desktop ("Only in Stage Manager")

## Terminal font
Set the terminal font to "JetBrainsMono Nerd Font" (installed via Brewfile)
so eza/starship icons render.
